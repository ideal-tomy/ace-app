## 1. 再現と原因

### 来店者カード

320px・日本語フォントで `RenderFlex overflowed by 26 pixels on the bottom` を再現した。固定の `childAspectRatio: 1.9` により、狭幅では名前・モード・入店時刻・余白に必要な高さを下回っていた。

修正では `mainAxisExtent` を使用し、フォントの実測行高とTextScalerから必要な高さを算出する。通常は２列を維持し、文字拡大で１カードの幅が足りなくなる場合は１列にする。名前の１行省略は維持し、人数も同じ行に表示する。警告を隠すためのClipRect/OverflowBoxは追加していない。

### フード

短い商品名10件の一覧は、320×667pxでも末尾へスクロールして10品目を選択できた。カートを開くと表示領域が縮むため再度スクロールする必要があるが、最後の行を全体表示でき、管理リンクとの重なりはなかった。

追加で長い商品名を２行表示したところ、320pxで商品ボタン内に5pxの縦overflowを再現した。フードグリッドの行高を `96 × textScaler.scale(16) / 16` にし、２行の名前・金額・余白を確保した。タブ、並び順、リンク、カートの構成は変更していない。

### 時間調整

入店２分では選択シートに60分の１候補しか出なかった。料金式ではなく、自動請求時間以下に限定した候補生成、Repositoryの上限チェック、減額のみを認める保存ルールと表示が原因だった。

## 2. 具体的な操作と料金

「会計対象時間」に現在の請求時間を大きく表示し、`−30分` / `＋30分` で変更する。60分が下限。上限では＋、下限では−を無効にする。「自動計算に戻す」で手動指定を解除する。

| 会計対象時間 | １名の時間料金 | ２名の時間料金 |
|---|---:|---:|
| 60分 | 1,200円 | 2,400円 |
| 90分 | 1,800円 | 3,600円 |
| 120分 | 2,400円 | 4,800円 |
| 150分 | 3,000円 | 6,000円 |

例: 実滞在２分・２名・商品900円の場合、自動は3,300円。＋30分で会計対象90分、時間料金3,600円、増額＋1,200円、最終会計4,500円となる。実滞在時間と商品代は変わらない。

保存を待っている間は時間操作と会計確定を無効にする。Firestoreの伝票更新により、同じ内訳計算を用いる時間カード・合計表示を更新する。表示する時間だけを先に変える処理は追加していない。

### 手動指定の最大時間

既存コードに開店時刻の設定はなく、来店日に対応する閉店３時の計算がある。このルールと時間料金の起算時刻（通常開始またはイベントからの切替時刻）を使用する。

上限は `billedMinutesFor(businessClosingAt(createdAt) − effectiveNomihodaiStartedAt)`。基本60分を下限に維持し、30分枠へ切り上げる。例: 18:10から翌03:00の530分なら最大540分、19:10からの切替なら最大480分。自動請求時間を超えても、この上限まではスタッフの明示操作で指定できる。

自動料金の閉店キャップは変更していない。30分枠へ切り上げるため、最後の枠の終端が実際の閉店時刻を数分超える場合があるが、既存の料金算出と同じ扱いである。Rules側は１営業サイクルの外側の上限1440分を検証し、Repositoryは伝票ごとの上限を検証する。

### 調整額の符号・保存・売上

- 既存フィールドの意味を維持: `timeChargeAdjustmentAmount = 自動時間料金 − 確定時間料金`。正なら減額、負なら増額。
- 表示は減額を `−¥600`、増額を `＋¥600` とする。会計サマリー、来店記録、日別売上の伝票行にも適用。
- 確定時の `billingAutoBilledMinutesFinal` と `billingBilledMinutesFinal` は従来どおり別保存。自動額・確定額・調整額の関係も維持する。
- 売上は既存の `finalAmount` / `eventAmountFinal` / `normalAmountFinal` に基づく。調整額を別途加算して二重計上しない。
- 時刻訂正で請求時間・金額を再計算しない。既存レコードの移行や符号変換はしていない。

### 秒の境界

店舗独自の秒単位ルールを新設せず、既存の `Duration.inMinutes` による整数分切捨てを維持した。

| 実経過 | １名の自動時間料金 |
|---|---:|
| 60分00秒 / 60分01秒 / 60分59秒 | 1,200円 |
| 61分00秒 / 90分00秒 / 90分01秒 | 1,800円 |
| 91分00秒 / 120分00秒 | 2,400円 |
